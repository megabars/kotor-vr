# Changelog / История изменений

## 0.0.1 — 2026-10-18

Initial public prototype / Первый публичный прототип.

- True per-eye geometry rendering through OpenXR with tracked third-person view / Отдельный рендер геометрии для глаз и отслеживаемая камера третьего лица.
- Ordinary mouse/keyboard control, extracted HUD and stereo Windows cursor / Обычное управление, выделенный HUD и курсор Windows в стерео.
- Full-screen panel, recenter, VR toggle and diagnostic capture / Полная панель, центрирование, переключение VR и захваты диагностики.
- Exact GOG 1.03 executable verification and process-local VDXR selection / Проверка точного EXE GOG 1.03 и выбор VDXR только для процесса.
- Source build, installer/settings restore, runtime ZIP and checksums / Сборка, установка/откат настроек, ZIP с бинарниками и контрольные суммы.
- Detailed English and Russian documentation / Подробная английская и русская документация.
