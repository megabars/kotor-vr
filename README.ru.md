# KotOR VR 0.0.1

[English documentation](README.md) · [Сборка из исходников](docs/BUILD.ru.md) · [Установка и диагностика](docs/INSTALL.ru.md) · [Устройство мода](docs/DEVELOPMENT.ru.md)

Экспериментальный VR-мод от третьего лица для **Star Wars: Knights of the Old Republic, GOG 1.03, Windows x86**. Геометрия мира отрисовывается отдельно для каждого глаза через OpenXR. Положение и повороты шлема изменяют игровую камеру. Управление остаётся обычным: мышь и клавиатура. Движения контроллеров и взмахи световым мечом не реализованы.

Прототип проверен на **Meta Quest 3S с Virtual Desktop/VDXR и NVIDIA RTX 3070**. Игрок подтвердил объём, отслеживание головы, видимый HUD, курсор, щелчки по объектам сцены и кнопкам интерфейса. Полное прохождение, все ролики, кат-сцены и графические эффекты **не проверены**. Это ранний прототип.

## Скачать и запустить

1. Скачайте `kotor-vr-0.0.1-windows-x86.zip` из [релиза v0.0.1](https://github.com/megabars/kotor-vr/releases/tag/v0.0.1). Автоматические архивы исходников GitHub не содержат готовых DLL/EXE.
2. Распакуйте архив целиком. При необходимости установите [Microsoft Visual C++ Redistributable x86](https://aka.ms/vs/17/release/vc_redist.x86.exe). Нужен именно **x86**, даже на 64-битной Windows.
3. Закройте KotOR. Откройте PowerShell и выполните команду, заменив пути:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 'C:\Downloads\kotor-vr\install.ps1' -GameDirectory 'D:\Games\Star Wars - KotOR'
```

4. Наденьте шлем и подключитесь к этому ПК через Virtual Desktop. Закройте активный VR-сеанс другого приложения. VDXR должен быть установлен вместе с Virtual Desktop Streamer.
5. Откройте `KotOR VR.lnk` в папке игры. Загрузите сохранение обычным способом. Посмотрите вперёд и нажмите **F10** для центрирования.
6. Если для меню, диалога или отдельных элементов интерфейса нужен полный исходный экран, нажмите **F9**.

Установщик копирует мод в `<игра>\kotor-vr`, создаёт ярлык, сохраняет резервную копию `swkotor.ini` и задаёт `FullScreen=0`, `AllowWindowedMode=1`, `V-Sync=0` в `[Graphics Options]`. EXE игры на диске и сохранения не изменяются. Ручная установка и откат описаны в [подробном руководстве](docs/INSTALL.ru.md).

## Совместимость

Установщик и лаунчер принимают только `swkotor.exe` с SHA-256:

```text
9c10e0450a6eeca417e036e3cde7474fed1f0a92aab018446d156944dea91435
```

Проверьте свою копию:

```powershell
Get-FileHash 'D:\Games\Star Wars - KotOR\swkotor.exe' -Algorithm SHA256
```

Одной надписи GOG 1.03 недостаточно: при другом хеше сборка не поддерживается. Steam, дисковые издания и изменённые EXE не проверены. Проверка хеша необходима, потому что перехваты используют конкретные адреса функций. В репозитории и релизе нет EXE или ресурсов оригинальной игры: нужна собственная установка KotOR.

## Управление

| Ввод | Действие |
| --- | --- |
| Штатные мышь и клавиатура | Перемещение, выбор целей, взаимодействие, интерфейс |
| Движение и повороты шлема | Изменение VR-обзора от камеры третьего лица |
| F9 | Показать/скрыть полную панель исходного игрового экрана |
| F10 | Центрировать положение и горизонтальное направление головы |
| F11 | Приостановить/возобновить отправку VR-кадров |
| F8 | Сохранить диагностические виды глаз и обычный кадр в BMP рядом с DLL |

На мониторе остаётся обычное изображение игры. HUD выделяется из исходного кадра и рисуется поверх стереоскопического мира. Курсор Windows, включая смену значков при наведении, рисуется отдельно в обоих глазах с увеличением в 1,5 раза. В сцене используется глубина под исходной позицией мыши, над интерфейсом — плоскость HUD. Для щелчков окно игры должно быть в фокусе, а мышь — внутри него.

## Содержимое проекта

| Путь | Назначение |
| --- | --- |
| `src/` | Лаунчер, перехваты игры, OpenXR, HUD, курсор, ресурсы версии |
| `deps/` | Исходники OpenXR SDK и MinHook с лицензиями |
| `tests/` | Проверки рабочих матриц, смещения глаз и проекции курсора |
| `build.ps1` | Настройка MSVC x86, сборка и запуск CTest |
| `install.ps1`, `restore-settings.ps1` | Установка и восстановление трёх видеоопций |
| `package.ps1` | Архив релиза с версией и контрольными суммами SHA-256 |
| `docs/` | Подробные руководства на английском и русском |
| `licenses/` | Лицензии зависимостей для распространения бинарников |

`bin/`, `build/`, `dist/`, личные резервные копии настроек и диагностические файлы исключены из Git. **Готовые бинарники распространяются через GitHub Releases.** После получения репозитория и инструментов сборки доступ к сети для зависимостей не требуется: их исходники уже включены.

## Ограничения и диагностика

- Поддерживается только указанный EXE. Другие шлемы и OpenXR runtime не проверены.
- Помимо обычного кадра выполняются отдельные проходы геометрии для каждого глаза. Нагрузка выше, чем у оригинала; конкретная частота кадров не гарантируется.
- Меню, видео, диалоги и некоторые эффекты могут требовать F9. Разностная маска HUD иногда захватывает экранные эффекты.
- Контроллеры Quest не управляют игрой. Совместимость с другими модами, особенно меняющими графику, широко не проверялась.
- Щелчки обрабатывает оригинальная игра. Совпадение курсора подтверждено в проверенных сценах, но не для всех камер и эффектов.
- Если нет явного переопределения, лаунчер выбирает установленный 32-битный runtime Virtual Desktop только для себя и дочерней игры. Системный OpenXR runtime не меняется.

Журнал: `<игра>\kotor-vr\bin\kotor-vr.log`, перезаписывается при запуске. Проверка шлема отдельной сценой: `bin\kotor-vr-probe.exe --seconds=15`. Проверки без шлема: `bin\kotor-vr-math-test.exe`. Перед сообщением об ошибке смотрите [диагностику](docs/INSTALL.ru.md#диагностика). Удалите личные пути и снимки экрана перед публикацией журналов.
