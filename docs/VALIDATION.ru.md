# Проверки релиза 0.0.1

[English](VALIDATION.md) · [Устройство мода](DEVELOPMENT.ru.md)

Дата: 18.10.2026. Это запись проверок подготовки релиза, а не сертификация всей игры.

- Все четыре Windows x86 цели собраны в Release на MSVC 14.44.35207 / Windows SDK 10.0.22621.0. Ресурсы версии файлов/продукта содержат `0.0.1`, лаунчер `--version` выводит `0.0.1`.
- CTest успешно проверил рабочие стереоматрицы, смещения головы/глаз и проекцию курсора в Release.
- Интеграционная проверка установщика выполнена в отдельной временной папке с локальной копией поддерживаемого EXE. Проверены хеши скопированных бинарников, нужная секция INI, сохранение не-ASCII байтов, первая резервная копия при повторной установке, возврат исходных значений, удаление отсутствовавшего ключа, сохранение позднего изменения другой настройки и отказ до установки при неподдерживаемом EXE.
- Скрипты разобраны парсером, установка/откат выполнены в Windows PowerShell 5.1. Локальные тестовые EXE/настройки игнорируются и не распространяются.
- ZIP формируется по явному списку файлов, содержит лицензии и внутренние суммы бинарников. Файлы оригинальной игры, личные копии, отладочные символы и журналы исключены. Отдельный `SHA256SUMS.txt` идентифицирует опубликованный архив.

В предыдущих живых проверках прототипа на Quest 3S + Virtual Desktop/VDXR пользователь подтвердил объём, отслеживание головы, HUD, курсор и щелчки: см. [описание](DEVELOPMENT.ru.md#что-проверено). Релизная пересборка добавляет метаданные и скрипты распространения без намеренных изменений поведения рендера. Новый полный сеанс в шлеме именно этого упакованного архива не заявляется.

Повторить проверку установщика в репозитории после сборки:

```powershell
.\tests\install-test.ps1 -SupportedExe 'D:\Games\Star Wars - KotOR\swkotor.exe'
```

Тест не запускает и не меняет эту установку игры: EXE локально копируется в игнорируемый `test-output/`. Не публикуйте этот каталог.
