# Установка, использование и диагностика

[English](INSTALL.md) · [Главная](../README.ru.md)

## Перед установкой

Нужны собственная установленная KotOR с [точным поддерживаемым хешем EXE](../README.ru.md#совместимость), Windows x64, видеокарта/драйвер с поддержкой OpenGL игры и OpenXR OpenGL, Meta Quest 3S и рабочие Virtual Desktop в шлеме и Streamer на ПК. Эта комбинация проверена; остальные не проверялись. Установите [Visual C++ runtime x86](https://aka.ms/vs/17/release/vc_redist.x86.exe). Один раз запустите оригинальную игру для создания `swkotor.ini`, затем закройте её.

Релизный ZIP содержит четыре готовых файла в `bin/`, документацию, скрипты установки/восстановления и лицензии. Данных игры в нём нет. Распаковывайте с сохранением структуры каталогов. Если скачан **Source code (zip)** от GitHub, сначала соберите проект либо скачайте готовый архив Windows x86 из вложений релиза.

Для проверки архива сравните результат с отдельным `SHA256SUMS.txt`:

```powershell
Get-FileHash .\kotor-vr-0.0.1-windows-x86.zip -Algorithm SHA256
```

Внутри архива также есть суммы каждого бинарника. Суммы позволяют проверить совпадение с опубликованными файлами; это не сертификат подписи кода. Исполняемые файлы не подписаны.

## Автоматическая установка

Закройте целевую игру и выполните команду из каталога, куда распакован архив:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\kotor-vr\install.ps1 -GameDirectory 'D:\Games\Star Wars - KotOR'
```

`-GameDirectory` — папка с `swkotor.exe`, а не сохранениями. Переопределение политики выполнения действует только на этот процесс PowerShell. Нужны права записи в каталог игры; для защищённого Windows каталога потребуется доступное для записи расположение или терминал с повышенными правами.

Установщик проверяет EXE до изменения файлов, убеждается, что эта копия игры закрыта, и создаёт структуру:

```text
Star Wars - KotOR/
  swkotor.exe                  оригинальная игра, без изменений
  swkotor.ini                  изменены три видеоопции
  KotOR VR.lnk
  kotor-vr/
    bin/
      kotor_vr.dll
      kotor-vr-launcher.exe
      kotor-vr-probe.exe
      kotor-vr-math-test.exe
    backups/swkotor.ini.original
    scripts/Ini.ps1
    install.ps1
    restore-settings.ps1
    README.md, README.ru.md, VERSION, LICENSE, docs/, licenses/...
```

Первая резервная копия INI сохраняется при повторной установке. В `[Graphics Options]` задаются:

```ini
FullScreen=0
AllowWindowedMode=1
V-Sync=0
```

Остальные значения и не-ASCII байты INI сохраняются. Параметры `-SkipVideoSettings` и `-SkipShortcut` пропускают соответствующие шаги; если пропускаете настройки, задайте их вручную. Установщик не запускает игру и не меняет сохранения.

## Ручная установка и запуск без копирования

Распакуйте папку `kotor-vr` рядом с `swkotor.exe`, сохраните копию `swkotor.ini`, задайте параметры выше и запустите `kotor-vr\bin\kotor-vr-launcher.exe`. При такой структуре лаунчер сам определяет папку игры. Не копируйте `kotor_vr.dll` в системные каталоги и не переименовывайте её в DLL-прокси.

Чтобы хранить мод отдельно, передайте путь к игре:

```powershell
& 'C:\Mods\kotor-vr\bin\kotor-vr-launcher.exe' --game-dir 'D:\Games\Star Wars - KotOR'
```

DLL должна оставаться рядом с лаунчером. Аргументы оригинальной игры можно передать после `--`; лаунчер передаёт их без изменения, а поддержка аргументов зависит от самой игры:

```text
kotor-vr-launcher.exe [--game-dir DIR] [--xr-runtime JSON] [-- GAME_ARGS...]
```

`--version` печатает версию мода и завершает работу, `--help` выводит справку. При ошибке проверки EXE запуск прекращается; обходить проверку хеша для другой сборки нельзя.

## Virtual Desktop и выбор runtime

1. Запустите Virtual Desktop Streamer на ПК и подключитесь к нему из Virtual Desktop в Quest.
2. Наденьте/разбудите шлем и завершите активный VR-сеанс другого приложения.
3. Запустите ярлык. Лаунчер сначала использует явный `--xr-runtime`, затем унаследованный `XR_RUNTIME_JSON`. Если переопределений нет, выбирается следующий манифест, если он установлен:

```text
C:\Program Files\Virtual Desktop Streamer\OpenXR\virtualdesktop-openxr-32.json
```

4. При отсутствии стандартного манифеста OpenXR loader использует штатный поиск runtime. Для x86-игры нужен **32-битный** манифест. Для проверенного пути через VDXR SteamVR не требуется.

Для нестандартного расположения Streamer:

```powershell
.\bin\kotor-vr-launcher.exe --game-dir 'D:\Games\Star Wars - KotOR' --xr-runtime 'D:\Virtual Desktop Streamer\OpenXR\virtualdesktop-openxr-32.json'
```

Выбор влияет только на лаунчер и дочернюю игру, системная регистрация runtime не меняется. Если ранее задавали `XR_RUNTIME_JSON` в терминале, проверьте `$env:XR_RUNTIME_JSON`. Удалить переопределение только из текущего процесса можно командой `Remove-Item Env:XR_RUNTIME_JSON`. Не указывайте 64-битный манифест.

## Первый сеанс и управление

Загрузите сохранение обычным способом. Основная камера от третьего лица включает стереоотрисовку. Посмотрите вперёд и нажмите F10. Повороты и перемещения головы меняют обзор относительно этой камеры; персонажем по-прежнему управляет обычный ввод. Контроллеры Quest мышь и клавиатуру не заменяют.

F9 включает/выключает полное исходное изображение на панели в VR. Используйте её для меню, диалогов и сцен, которые неправильно отображаются через выделенный HUD. Отключите панель, чтобы вернуться к стереомиру без полного экрана перед ним. F11 приостанавливает/возобновляет отправку VR-кадров. F8 пишет BMP рядом с DLL и может вызвать краткую паузу и запись на диск; для обычной игры он не нужен.

Курсор отдельно рисуется в стерео: в мире учитывается глубина под исходной мышью, над обнаруженным интерфейсом — плоскость UI. Окно должно быть в фокусе; если сама игра скрывает курсор, мод не заставляет его появиться. Захват мыши, границы окна и поворот головы влияют на то, что оригинальная игра считает под указателем. При необычном несовпадении центрируйте обзор и сравните с изображением монитора.

## Инструменты диагностики

При закрытой игре и подключённом Virtual Desktop:

```powershell
.\bin\kotor-vr-probe.exe --seconds=15
```

Откроется независимая сцена с объёмным кубом на том же OpenXR backend. **R** центрирует обзор, **Escape** завершает тест. `--seconds=N` принимает 1–3600. В консоли выводятся runtime, состояния сеанса и число отправленных кадров. Это проверка OpenXR/шлема, а не перехватов игры. Не запускайте параллельно с другим VR-сеансом.

```powershell
.\bin\kotor-vr-math-test.exe
```

Проверяет рабочую математику без игры и шлема. Ненулевой код завершения означает ошибку проверки.

Мод пишет `bin/kotor-vr.log` рядом с внедрённой DLL. Файл перезаписывается при запуске: сохраните полезный журнал перед перезапуском. Ищите версию, установку перехватов, OpenGL/GPU, название runtime и растущие `STEREO frame=`. F8 создаёт `smoke-left.bmp`, `smoke-right.bmp` и дополнительные снимки исходного кадра. Эти изображения сами по себе не доказывают показ кадров в шлеме.

Переменные для разработчика: непустая `KVR_XR_DISABLED` отключает начальную отправку VR, непустая `KVR_SMOKE_TEST` ставит захват геометрии в очередь. Для обычного запуска удалите их из окружения процесса. Это диагностика, а не параметры качества.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Неподдерживаемый `swkotor.exe` | Сравните SHA-256, восстановите поддерживаемую легальную установку. Другая сборка требует переноса адресов, переименование EXE не помогает |
| Нет `VCRUNTIME140.dll` / `MSVCP140.dll` | Установите Microsoft VC++ Redistributable **x86** |
| Нет DLL / неправильная архитектура | Распакуйте весь релиз; x86 DLL должна находиться рядом с лаунчером |
| `XR_ERROR_FORM_FACTOR_UNAVAILABLE` | Наденьте/разбудите шлем, переподключите VD, закройте другое VR-приложение. Мод повторяет инициализацию примерно раз в пять секунд |
| Ошибки loader/runtime | Проверьте путь 32-битного манифеста и старый `XR_RUNTIME_JSON`, отдельно запустите probe |
| На мониторе игра есть, в шлеме пусто | Проверьте VD, журнал и runtime, нажмите F11 один раз, если отправка была остановлена; отдельно проверьте probe |
| Не видно меню или диалога | Включите полную панель F9 и верните фокус игре |
| Курсор или щелчки не совпадают | Верните фокус, поместите мышь в окно, попробуйте F10/F9, сравните с монитором; опишите сцену и шаги |
| HUD захватывает лишние эффекты | Известное ограничение разностной маски; используйте F9 и укажите эффект/сцену |
| Низкая производительность | Уменьшите разрешение игры либо параметры стриминга/рендера VD, закройте тяжёлые приложения; дополнительные проходы действительно требуют ресурсов |
| Игра не запускается | Проверьте прямой запуск `swkotor.exe`, чтобы отделить ошибки оригинала; сохраните вывод лаунчера и журнал |

В этой версии нет публичного файла настройки масштаба мира, IPD, расстояния HUD и размера курсора. Произвольные INI-ключи не поддерживаются; такие изменения требуют пересборки.

## Восстановление и удаление

Закройте игру и восстановите только три изменённые видеоопции:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 'D:\Games\Star Wars - KotOR\kotor-vr\restore-settings.ps1' -GameDirectory 'D:\Games\Star Wars - KotOR'
```

Скрипт читает `kotor-vr\backups\swkotor.ini.original`. Если ключа в оригинале не было, он удаляется; остальные текущие настройки сохраняются. Не удаляйте резервную копию до завершения восстановления. При ручной установке восстановите параметры по собственной копии INI.

Прямой запуск `swkotor.exe` работает без загрузки мода. После восстановления настроек можно удалить только `KotOR VR.lnk` и установленную папку `kotor-vr`. Если она одновременно является вашим репозиторием, сначала сохраните исходники и локальные изменения. Сохранения и оригинальные файлы игры находятся вне папки мода.

## Сообщение об ошибке

Укажите версию мода, SHA-256 EXE, Windows/GPU/драйвер, шлем, версию runtime/Streamer, другие моды, шаги воспроизведения из сохранения и результат отдельного probe. Приложите нужный журнал и при необходимости F8-снимки, предварительно проверив личные пути и изображения. Уточните, где видна проблема: на мониторе, в шлеме или в обоих местах. Не публикуйте EXE игры и сохранения без проверки содержимого и прав распространения.
